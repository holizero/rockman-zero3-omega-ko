The ZIP includes the offline patch tool, installation and restoration IPS files, instructions, and 11 gameplay GIFs. **No game ROM, save file, or emulator is included.**

Installation requires the Japanese base ROM: **8,388,608 bytes**, SHA-1 `ff7a801776dc76e6d8c7ef73a6660ae732934a3f`. Other translations, regions, and development builds are not supported as installation inputs.

A complete playthrough of every stage and boss, and compatibility with every existing save-data combination, have not been verified.
